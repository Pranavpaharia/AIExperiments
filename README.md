# AIExperiments

Experiments with **artificial intelligence in Unreal Engine 4** — a set of small C++ demos showing different AI approaches in one UE4 project (`AIExp.uproject`).

## What's inside
- **FSM** — finite state machine driven agent behavior
- **Behavior Trees** — UE4's BT system for decision making
- **EQS** — Environment Query System for spatial reasoning

Each experiment lives as a separate map/actor set under `Content/`, demonstrating the pattern in isolation so it is easy to study and re-use.

## Requirements
- Unreal Engine 4.18+ (project created on 4.18)

## How to run
1. Open `AIExp.uproject` in UE4.
2. Open the experiment map you want (check `Content/Maps`).
3. Press **Play**.

## Notes
This is an experiment/learning project — expect rough edges. It is intentionally small so each AI pattern is easy to follow.
